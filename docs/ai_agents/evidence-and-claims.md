# Evidence and claims

Automation retains [evidence-model](../evidence-model.md) claim boundaries and
[topic-manifest](../topic-manifests.md) recording standards. Before submission:

- Identify image/exact guest locators.
- Separate observation from interpretation.
- Retain confidence, alternatives and falsifiers.
- Bound negative searches by inspected range/truncation.
- Infer no runtime behavior from static code or tool success.
- Preserve citations, addresses, hashes, measurements and identifiers.
- Keep raw output in scratch and each finding in one canonical home.

Follow [catalog contract](../catalogs.md) for promotion; endpoint evidence alone
does not prove a relation.
